## Design Specificity Verdict

LLM: Twitter's design system with the word "peep" in it — accent is Twitter blue #1d9bf0, dark palette is Twitter's, shell is pills + cards + sidebar + blue check. Only the trust-rule copy and danger-zone warning are authored for this product. No mark, no wordmark.

Deterministic scan: CLI found 1 finding (side-tab, main.css:82) — false positive (neutral thread indent rail), discarded. In-page detector across 3 viewport/theme runs: 4 real defects — white-on-#1d9bf0 buttons 3.0:1 (all themes), light h1 2.8:1, light muted 4.4:1, h1→h3 skip. No overflow at any width; zero app console errors.

## Priority Issues

- **[P0] Anonymous replies succeed visibly and vanish silently** — actions.rs:106 skips the inbox pointer when attestation is None; composer clears as if it worked. Fix: inline notice in composer ("Followers-only — a Ghost Key puts it in the thread →"), confirm applied visibility. (clarify)
- **[P1] Every interactive affordance fails WCAG AA contrast** — --accent #1d9bf0 at 3.0:1 as button fill and link text (main.css:5,7,61-63). Fix: split token, add --accent-text ≈#0f6fb8 for light mode; darken light --muted. (colorize)
- **[P2] Theme toggle is a per-session illusion** — sandbox lacks allow-same-origin, localStorage throws, state.rs:74/94 swallow it. Fix: persist theme in delegate via kv_request. (harden)
- **[P2] Identity is a 44-char string and nothing else** — key-fallback names, no preview before follow, no copy button, no identicons. Fix: copy buttons, feed preview in follow banner, deterministic identicon. (delight/onboard)
- **[P3] Profile edit is a trap door** — no cancel, placeholder-only labels, failed save silently dropped (views.rs:724). Fix: cancel link, labels, surface Err. (harden)

## Minor Observations

- Tab title "dioxus | ⛺" (default template in production).
- Char counter counts bytes; CJK/emoji cap at ~1/3; button disables with no message.
- Timeline truncates at 100 silently; ago() computed at paint only; Thread's loading and empty share one string.
- Ghost Key link target=_blank without rel=noopener while sandbox grants popups-to-escape.
- Profile is a signal not a route: unlinkable, Back exits app; post authors not clickable.
- Armed danger zone: destructive confirm is highest-contrast control; escape hatch is a 13px link.

## Questions to Consider

1. If the trust rule is the product, why is it invisible at the single moment it applies — what if the reply button itself were the pitch?
2. Is a Twitter-shaped shell right for a network where nobody can recognize anybody, or does identity design (identicons, name resolution) come before timeline design?
3. When does "the browser is just a renderer, the node is the app" become a stated design principle instead of a constraint worked around?
